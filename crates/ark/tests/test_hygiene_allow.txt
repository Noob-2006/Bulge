# Grandfather list for `crates/ark/tests/test_hygiene.rs`. Every line is a file that still
# needs fixing; the list may only shrink.
#
# Two rules the lint enforces:
#   1. a file that calls `env::temp_dir()` directly must instead use `ark_core::tmp::TempDir`
#      (`TempDir::new(prefix)` / `TempDir::new_in(base, prefix)`), which deletes its tree on drop;
#   2. test code must not signal processes it did not start (`Command::new("kill")`, "pkill",
#      "killall") and must not read the real `$HOME` (`env::var("HOME")` / `env::var_os("HOME")`)
#      — tests get `ARK_HOME`/a scratch home of their own.
#
# Entries are sorted and carry a reason column. Removing a line is the point: fix the file, then
# delete its line. A line for a file that no longer matches is itself a lint failure, so the list
# cannot rot. Do not add a line to silence a new leak in code you are writing.
#
