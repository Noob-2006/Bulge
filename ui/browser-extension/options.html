ark browser relay

This extension lets a local ark agent drive your own tabs. It only talks to 127.0.0.1 and never sends anything to the network.

Relay

browser.extension_control.port in ark's config (default 18792).

Contents of ~/.local/share/ark/browser/extension-token (created by ark browser extension).

Checking…

On the ark side

  1. ark browser extension — starts the loopback relay and prints the token path.
  2. Load this folder (ui/browser-extension) via chrome://extensions → Developer mode → Load unpacked.
  3. Paste the token above and press Save & connect.
  4. Set browser.extension_control.enabled = true and browser.backend = "extension".
