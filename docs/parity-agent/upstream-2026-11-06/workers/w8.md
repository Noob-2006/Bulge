# W8 — memory, research and skills

Worktree: `w8` (changes left uncommitted). No new third-party dependencies, no whole-workspace test run.

## 1. Hermes #4 — per-skill lock — **done**

A user lock lives in the existing `skills/.usage.json` record (`locked: true`), so it is visible to
the CLI, curator and every write path.

- `crates/seagent-skills/src/core/usage.rs`: `set_locked`, `locked_names`, `is_locked`, shared
  refusal texts. `archive` refuses a locked skill.
- `crates/seagent-skills/src/core/manage.rs`: every mutating op (including `create`, which would
  otherwise let a delete+recreate bypass the lock) refuses before planning.
- `crates/seagent-skills/src/core/skilltool.rs`: the builtin writer route and `operations` batches
  refuse locked skills.
- `crates/seagent-skills/src/core/curator.rs`: auto-transitions skip locked skills.
- `crates/seagent-skills/src/hub/cli.rs`: `seagent skills lock <name>` / `unlock <name>` (catalog
  lookup first, so a typo forges nothing).
- `crates/seagent-kernel/src/secgate.rs`: floor `skill-lock` for (a) the `skill` tool, (b) every
  `Effect::Write` inside `skills/<name>` (profile, project, `.claude`, external roots), (c) the lock
  record, and (d) shell redirection/`rm`/`mv`/`sed -i`/`tee`/inline writes into a locked directory.
  It also refuses `seagent skills unlock` / `curator unlock` from the agent shell — only the
  operator's own CLI lifts a lock.

Tests: `secgate::tests::skill_locks_refuse_every_agent_write_path`,
`core::manage::tests::create_update_patch_with_guards_ledger_and_lint` (extended),
`hub::cli::tests::lock_unlock_cli_records_the_user_lock`.
Limitation: the shell check is a policy check over the command text, not a sandbox; an obfuscated
program that writes through its own logic is not seen (same limitation as upstream).

## 3. OpenClaw-ext #6 — decision-model recall gate — **done**

- `crates/seagent-memory/src/active.rs`: `RecallGate` lifecycle + `gate`:
  keyword shortlist over the wiki (`max_candidates`), per-page independent probability from one
  aux/decision-model call, thresholds, `off`/`shadow`/`live`, 1.5 s default budget, page/total
  injection caps, medium pointer tier, skip hint when all scores are low. `shadow` writes the same
  decision to `<data>/logs/recall-gate.jsonl` and injects nothing; model failure/timeout is logged
  as `unavailable`, never a fake hit.
- `crates/seagent-memory/src/settings.rs`: `[memory.recall_gate]` (`mode`, `candidates`,
  thresholds, `timeout_ms`, `max_candidates`, `page_chars`, `max_inject_chars`, `store`, `model`).
- `crates/seagent-kernel/src/config.rs`: `MemoryConfig.recall_gate`.
- `crates/seagent-memory/src/lib.rs`: lifecycle registration.

Test: `active::tests::recall_gate_live_shadow_and_no_model`.
Limitation: `candidates = "model"` (label-index shortlist) is deliberately refused; only the
measured keyword shortlist is implemented.

## 5. OpenClaw-ext #8 — knowledge vault — **done (first solid slice)**

- `crates/seagent-memory/src/wiki.rs`:
  - per-store ACL: `[memory.wiki] agent_id` (else `$SEAGENT_AGENT`), default-store `agents`, and
    `[memory.wiki.stores.<name>] { path, agents }`; tools and `seagent wiki … --store <name>` resolve
    and authorize before any read/write; missing/path-less stores and unknown agents fail closed.
  - history: every semantic mutation snapshots the previous page under
    `.seagent-wiki/history/<page>/` (bounded by `history_max`); `wiki_history` tool and
    `seagent wiki history <lookup>`.
  - supersede: `wiki_apply {"op":"supersede","lookup":…,"by":…,"reason":…}` marks the old page
    superseded, records `supersededBy`/`supersededAt`, appends `supersedes` on the current page;
    search follows the chain and returns the current record.
- `crates/seagent-memory/src/settings.rs`: `WikiStore`, `agent_id`, `agents`, `stores`, `history`,
  `history_max`.
- `crates/seagent-memory/src/tools.rs`: existing wiki-backed memory paths still use the default store.

Test: `wiki::tests::store_acl_history_and_supersede_chain`.
What is left of the L-sized item: the other ~33 `knowledge_*` tools, journaled Git history,
merge/withdraw/verify workflows, chronicle/timeline and per-relation ACLs. The ACL/history/supersede
foundation and the 6 `wiki_*` tools are in place.
