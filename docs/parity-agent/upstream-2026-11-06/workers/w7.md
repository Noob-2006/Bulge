# W7 — daemon, automation and ops backend

Branch worktree: `w7`. All changes are left uncommitted in the working tree.

## Items

### 1. OpenClaw-core #4 — cron default delivery / failure-alert destinations — **done**
Added `[automation] default_deliver`, `default_failure_deliver`, `agent`, `[automation.agents.<id>]` and `[automation.creators.<profile>]` routes. Resolution is job → creator → owner agent → gateway, per field; failures first use the job's own `failure_deliver`, then its `deliver`, then the scoped/gateway failure route, finally `origin`. New jobs record the owner agent (`[automation] agent`) and the creating profile (`SEAGENT_PROFILE`). Delivery call sites now pass the live config defaults.
- Files: `crates/seagent-kernel/src/cronjob/mod.rs`, `crates/seagent-kernel/src/automation.rs`.
- Tests: `cronjob::tests::delivery_defaults_fall_back_job_creator_agent_gateway`.

### 2. Hermes #17 — cron `deliver: room:<id>` — **done**
Added `Target::Room`, parsing/rendering `room:<id>[@profile]`, and a room-store append (`message.gateway`, actor `cron`) that records the @mentions the job named but does not auto-start a discussion. The outbound host now takes the data dir so room targets resolve to `<data>/rooms`.
- Files: `crates/seagent-kernel/src/outbound.rs`, `crates/seagent/src/ops/rooms.rs`, `crates/seagent/src/outbound_host.rs`, `crates/seagent/src/main.rs`.
- Tests: `outbound::tests::parses_and_renders_targets`, `ops::rooms::tests::cron_post_appends_a_labelled_message_and_mentions`.

### 3. Hermes #18 — one-shot due during drain/restart is not retired — **done**
Claims now persist their pre-claim state (`next_run`, `enabled`, `runs`, `last_run`) atomically inside `schedules.json`. `recover_claims` restores a claim younger than `[automation] restart_hold_seconds` (default 3600) to due; an older claim is recorded as missed instead of silently disappearing. The daemon calls recovery on becoming leader and refuses to claim new work once draining.
- Files: `crates/seagent-kernel/src/automation.rs`, `crates/seagent-kernel/src/daemon.rs`.
- Tests: `automation::tests::a_claim_interrupted_by_a_restart_is_restored_not_missed`.

### 4. OpenClaw-core #9 — stop attribution + `run_stopped` hook — **done**
Added `Kernel::interrupt_as(session, actor, source)`: cancels the run, writes an audit `run.stopped` event with the actor/source, and fires the new `RunStopped` hook (`run_stopped` accepts OpenClaw's name). `session.interrupt` uses the authenticated `_by`/`_by_role` from the app server; `/stop` uses the local actor. Internal stops (shutdown, failover) still use `interrupt` and are not announced as user stops.
- Files: `crates/seagent-kernel/src/kernel.rs`, `crates/seagent-kernel/src/hooks.rs`, `crates/seagent-kernel/src/daemon.rs`, `crates/seagent-app/src/server.rs`, `crates/seagent/src/slash.rs`.
- Tests: `daemon::session_command_tests::explicit_stop_records_the_actor_and_fires_run_stopped`.

### 5. OpenClaw-core #10 — scratch (24 h) and idle worktree expiry — **done**
New `seagent_kernel::scratch` pass expires old entries under `<data>/tmp`, `<data>/scratch`, `<data>/art` and per-session `artifacts/` (live sessions skipped, symlinks never followed), and reclaims clean, empty `<repo>/.worktrees/*` trees whose newest file is older than the idle threshold. Config: `[automation] scratch_ttl_hours` (24), `worktree_idle_hours` (168), `cleanup_interval_secs` (3600); 0 disables. Runs from the daemon’s scheduler loop.
- Files: `crates/seagent-kernel/src/scratch.rs` (new), `crates/seagent-kernel/src/worktree.rs`, `crates/seagent-kernel/src/daemon.rs`, `crates/seagent-kernel/src/lib.rs`.
- Tests: `scratch::tests::expires_old_scratch_and_live_or_fresh_artifacts`, `scratch::tests::settings_default_and_zero_disables`, `worktree::tests::prune_idle_respects_age_and_symlinks`.

### 6. Hermes #25 — idle session retirement in seagentd — **done**
`Kernel::retire_idle_sessions` drops per-session in-memory state (queue settings, session tools, end-turn marks and the context caches) for non-running sessions idle longer than `[automation] idle_session_secs` (default 1800, 0 off). The transcript stays on disk and state is rebuilt from config/events on the next use. Wired into the daemon loop.
- Files: `crates/seagent-kernel/src/kernel.rs`, `crates/seagent-kernel/src/daemon.rs`.
- Tests: `daemon::session_command_tests::idle_sessions_are_retired_from_memory_and_rebuilt_on_demand`.

### 7. OpenClaw-core #8 — direct policy-gated `tools.call` — **done**
Added `Kernel::call_tool_as`: one tool call through the normal pipeline (`self.tool` policy, `tool_request`/`pre_tool` hooks, security gate/approvals, `ToolCalled`/`ToolSettled`, result transforms, redaction/spill) plus an explicit `tool.call` audit event. The ARP `tools.call` method accepts `tool`/`name`, `input`/`arguments`, optional `session` (a fresh session is created otherwise) and `workspace`; MCP `mcp__server__tool` names are ordinary tools. It is admin-scope by default (unrecognised method). The app server forwards the principal so the audit names the caller.
- Files: `crates/seagent-kernel/src/kernel.rs`, `crates/seagent-kernel/src/daemon.rs`, `crates/seagent-app/src/server.rs`.
- Tests: `daemon::session_command_tests::tools_call_goes_through_the_same_log_and_audit`.

### 8. Hermes #26 — busy-arrival metrics — **done**
The kernel reports `queued` / `steered` / `dropped` busy arrivals through a host-installed observer; `seagent-app` exports `seagent_busy_arrivals_total{outcome=…}`, `seagent_busy_chats_today` and `seagent_busy_chats_daily_peak` (day-scoped, no content or session ids exported).
- Files: `crates/seagent-kernel/src/kernel.rs`, `crates/seagent-app/src/metrics.rs`, `crates/seagent/src/wire.rs`.
- Tests: `metrics::busy_tests::busy_chats_are_day_scoped_and_peak_is_kept`, `metrics::busy_tests::busy_arrivals_only_use_the_fixed_outcome_vocabulary`.

### 9. Hermes #31 — `seagent migrate` credentials opt-in — **done**
`--migrate-secrets` is a new boolean flag and is **off by default**. Without it every `Act::Secret` is removed and a `skipped credential NAME (use --migrate-secrets …)` note is printed; no vault value is written. With it the previous behaviour is unchanged.
- Files: `crates/seagent/src/ops/migrate.rs`.
- Tests: `ops::migrate::tests::credentials_are_opt_in_and_skips_are_named`.

### 10. Hermes #32 — opt-in unattended plugin auto-update — **done**
`[automation] plugin_auto_update_hours` (default 0 = off) gates a daemon maintenance pass. It reuses the install path (guard scan, signature/trust check, `[security] install_policy` and consent), so a `caution` candidate is skipped rather than force-accepted; pinned checkouts and source-less plugins are skipped. The replacement decision is now separate from `--force`, which also fixes `plugins update` silently accepting caution verdicts.
- Files: `crates/seagent-skills/src/hub/plugins.rs`, `crates/seagent-kernel/src/daemon.rs`, `crates/seagent/src/main.rs`.
- Tests: `hub::plugins::tests::unattended_update_is_opt_in_and_still_scans`.

### 11. OpenClaw-core #7 — node-hosted MCP tools — **partial (first tested slice)**
`node.toml` now accepts `[mcp.<server>]`. The node starts those MCP servers locally and advertises each tool as an `mcp__<server>__<tool>` node command (description/schema/dangerous flag), invokable through the existing `node.invoke` path (`node_invoke` tool). Credentials and the MCP process stay on the managed host.
- Files: `crates/seagent-app/src/node.rs`.
- Tests: `node::tests::node_hosted_mcp_servers_expose_tools_as_commands`.
- Left: gateway-side first-class registration of node MCP tools as agent tools, and forwarding MCP elicitation/sampling to the operator through the gateway. The current slice deliberately exposes them as node commands, not as model tools.

### 12. Security — host paths hidden from read-only ARP callers (9341d60e90b) — **partial**
The app server now forwards the caller's scope to the daemon. For `scope:read` and the `auditor` role, `session.list`, `session.view`, `schedule.list` and `goal.list` omit the `workspace` field (and `session.view` omits it entirely); the local unix socket and admin/write callers keep the old answers. A raw `session.history`/`session.attach` event stream (which is conversation content) can still contain paths inside tool inputs/results, so that remains open.
- Files: `crates/seagent-app/src/server.rs`, `crates/seagent-kernel/src/daemon.rs`.
- Tests: `daemon::session_command_tests::read_only_callers_do_not_get_host_paths`.
