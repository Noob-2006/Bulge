# 介面設計語言：Instrument

桌面版（`crates/bulge-app`）和 Bulge Remote（`crates/bulge-mobile`）共用一套設計語言：介面像一台精密儀器，安靜、清楚，只有狀態和數據會發光。

## 來源

- **瑞士設計**：8 px 網格、靠左對齊、層級分明的字級、編號的小標題（`01 — 模型`）、細線分隔、只用一個訊號紅。
- **Apple**：系統字型（SF／PingFang；Windows 用 Segoe／微軟正黑體；其他用 Noto）、毛玻璃側欄與面板、分組的圓角清單（像「設定」App）、柔和的圓角與動畫。
- **科幻，但只在有資訊的地方**：等寬字的遙測數字（步數、時間、token）、狀態燈、工作進行時頂列下緣的掃描線、背景極淡的量測格線。

## 檔案

| 檔案 | 內容 |
|---|---|
| `ui/theme.css` | 設計變數（顏色、字型、間距、圓角、動畫）和共用元件（`.label`、`.led`、`.icon`、`.grid-canvas`）。兩個 app 的 `build.rs` 會把它複製進各自的 `dist/`。 |
| `ui/palette.js` | 斜線指令選單，樣式讀 `--palette-*` 變數。 |
| `crates/bulge-app/dist/style.css` | 桌面版版面：側欄、畫布、浮動輸入框、審批面板、設定面板。 |
| `crates/bulge-mobile/dist/style.css` | 手機版版面：大標題、分組清單、聊天、安全區域。 |

## 規則

- **顏色有意義**：紅色（`--signal`）只用在「動作」：主要按鈕、選取標記、編號。青色（`--live`）只用在「正在發生」：執行中、網路、連結。綠／黃／紅狀態色只用在結果。其餘都是灰階。
- **自己的訊息用黑白**，不用品牌色：長段文字用彩色底很累，紅色留給動作。
- **量測值用等寬字**（`--mono`），數字等寬對齊（`tnum`）。
- **小標題**：等寬字、大寫、字距 0.14em、`--ink-3`，前面一小段紅線或編號。
- **深色是預設**；`[data-theme="light"]` 覆寫。桌面版可手動切換，Remote 跟隨系統。
- **動畫**只用 120／200 ms 的 `--ease`，並尊重「減少動態效果」設定。
- **圖示**是內嵌 SVG 線條（`<use href="#i-…">`），顏色跟著文字，不用 emoji。

## 預覽

`~/bulge-dist/ui-preview/` 有各畫面的渲染圖（深色／淺色、執行中、審批、指令選單、設定、Remote）。渲染方式：用 headless Chrome 載入真正的 `dist/` 檔案，搭配一個假的 `window.__TAURI__`，用範例資料和一個真實工作的事件紀錄回放。
