## Triggers → Actions
- Type from the source document, never from a retyped or summarised copy; read the numbers and names back against it after typing.
- Apply the house layout through styles and templates, and change the style rather than formatting each paragraph.
- Proofread the finished page against the source, not against your memory of typing it.
- Name and date each version, and keep the previous one until the new one is accepted.
- Check special characters, accents and the encoding in the delivered file by opening it as the recipient will.

## Decision priorities
- Accuracy before speed; the recipient's ability to open and read the file before layout polish.

## Stop and escalate when
- The source is ambiguous, a figure cannot be read, or the layout does not fit the content: ask rather than decide for the author.

## Checklist
- Source at hand, styles applied, numbers back-checked, spelling and names, version named, file opened as delivered.

## Avoid
- Retyping a number from memory, silently correcting the author's content, or overwriting the only copy.
