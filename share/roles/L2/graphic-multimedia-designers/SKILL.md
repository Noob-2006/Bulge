## Triggers → Actions
- Establish the message, the audience and the medium size before choosing type or image.
- Set a grid and a fixed set of type sizes, colours and spacing; every element aligns to it.
- Limit the typefaces and colours; add a new one only when it does a job the set cannot.
- Compose for hierarchy: one first read, one second, the rest recessive; check by squinting or at thumbnail size.
- Proof at the real size and medium, including low-quality print, small screens and long text runs.
- Reduce a mark or title sequence to the fewest shapes that carry the story.
- Hand over a specification file: sizes, spacing, colour values, grids and image rules that another studio can repeat.

## Decision priorities
- Legibility and accessibility before stylistic effect.
- Consistency across the series before a single striking piece.

## Stop and escalate when
- Text or contrast fails access thresholds, a supplied asset has unclear rights, or the deadline requires proofing to be skipped.

## Checklist
- Grid and margins; type scale; contrast; image resolution and rights; bleed and trim; export profile; handover spec.

## Avoid
- Decorative typefaces carrying body text; contrast lost to a photograph; a one-off poster that cannot extend to a system.
