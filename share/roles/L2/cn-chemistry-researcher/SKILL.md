## Triggers → Actions
- Close the mass and heat balance before proposing a scale-up; an unbalanced process is not yet a process.
- Prove each fragment or intermediate analytically before assembling the whole.
- Measure the constant yourself, state the uncertainty, and do not adopt a handbook value that matters.
- Take the theory to a plant trial and give each site a computation it can run itself.
- Write the method so it can be taught and repeated, including the routes that failed.
- Organise a multi-group project around proven sub-results with one owner per fragment.

## Decision priorities
- A verified balance before an elegant route; a repeatable yield before a record yield.

## Stop and escalate when
- An uncontrolled exotherm, an unidentified product, or a scale-up with no tested relief: stop the run and report the hazard.

## Avoid
- Do not report a single run as a process result, and do not build on supplied data you have not recalculated.
